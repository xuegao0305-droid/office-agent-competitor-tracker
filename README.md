# 办公 Agent 竞争追踪台

这是 DuMate、WorkBuddy、千问办公和 TRAE Work 的持续调研页面。

在线页面：https://xuegao0305-droid.github.io/office-agent-competitor-tracker/

页面使用左侧多页目录。默认首页先回答四家最近新增了什么能力，再用一句话说明每家正在往哪里发展。完整功能台账、客户合作和公开体量作为下一层证据，用来验证方向判断。当前数据快照日期是 2026 年 7 月 31 日。

十一张原始截图都放回对应产品的拆解中。截图说明产品入口、项目结构、组织渠道和工作模式如何形成差异，不再作为独立证据墙展示。

企业合作模块收录 33 条公开记录。页面会把当前产品、前身能力和同厂商账户分开，也会区分明确采购、较强部署、使用未披露采购、生态活动和待核线索。

## 本地运行

```bash
npm install
npm run dev
```

打开终端显示的本地地址。

## 更新数据

产品方向和更新数据放在 `app/data.ts`。企业合作名单放在 `app/company-cases.json`。

每次更新时按下面的顺序处理。

1. 先补充最近新增功能，并标明日期和来源。
2. 把同一阶段的多条更新连起来，更新每家的一句话方向结论和证据边界。
3. 检查客户与合作是否支持产品方向。
4. 补充可归因的体量数据，并写明口径边界。
5. 最后更新对 DuMate 的启示和下一步观察。

更新企业合作名单时，还要保留下面这些字段。

1. 公开使用产品和目标产品的映射。
2. 合作方、行业、合作类型和公开动作。
3. 公开规模或结果。
4. 能否证明采购或收入。
5. 销售与竞争含义、日期、来源类型和来源链接。

来源表是 `办公Agent企业合作表_mapping补全_20260731.xlsx`。不要把接入、授权、活动或免费资源投放直接写成成交。

页面中的追踪录入功能会把记录保存在当前浏览器。请及时导出 JSON。浏览器里的记录不会自动写回 GitHub。
